# Integration parity matrix

This matrix is the release checklist for every external workflow exposed by
Vynode. A row is **complete** only after configuration validation, production
requests, payload normalization, failure/cancellation behavior, automated
tests, UI review, and real-service read-back have all passed.

## Current rule

No UI badge, saved form, or simulated probe counts as an implemented
integration. Unsupported workflows must fail explicitly and must never report a
successful synchronization.
