A route is not considered ported until its page, nested tabs, empty/loading/
error states, controls, dialogs, row actions, helper text, API effects, and
responsive behavior have been reviewed and verified.

Global application surfaces:

- Desktop sidebar and mobile drawer with active-route state, narrow-width overflow protection, initial navigation focus, Escape close, and trigger-focus return.
- Header/account trigger uses the authenticated role and principal, exposes semantic menu items, closes by outside click/Escape with focus return, and reports sign-out failures without discarding the session; dynamic version/update status remains pending.
- Authentication and activation route guards distinguish an unauthenticated response from a service/network failure and provide session-check recovery. Activated backend APIs enforce sessions, viewer reads, operator actions, and administrator configuration changes while preserving public health, onboarding, Plex authentication, and Plex webhook entry points. The shell hides inaccessible routes, renders direct-navigation permission states, and makes viewer placement/dashboard controls read-only.
- Global sync progress, notifications/toasts, dialogs, keyboard focus, loading,
  empty, permission-denied, offline, and fatal-error states.
- Posters tabs: Poster Overlays and Collection Posters.
- Settings tabs: General, Plex, Sources, Downloads, Logs, Jobs, and About.
